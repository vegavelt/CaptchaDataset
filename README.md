# CAPTCHA Dataset

This repository contains a synthetic 3-character CAPTCHA dataset and the saved weights for a convolutional neural network used in the project at https://github.com/vegavelt/Captcha-Recognition.

You can copy the `Dataset` folder and the `coefficients.csv` file from the `SavedNN` folder into the main directory of the Captcha-Recognition project, then compile and run `NeuralNetworkTest.cpp`.

## Repository structure

- `Dataset/images/`: CAPTCHA image samples
- `Dataset/labels.csv`: filename-to-label mapping
- `SavedNN/coefficients.csv`: saved neural network coefficients
